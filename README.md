# Inference-Specialist-Portfolio-Project
### By Faatimah Majothi

#### Introduction:
This project was created for the ["Data Scientist: Inference Specialist" career path](https://www.codecademy.com/enrolled/paths/data-science-inf) portfolio project on [Codecademy](https://www.codecademy.com/learn), as a showcase of the skills developed through the course path.

#### Project Goals:
- Define the treatment, outcome, and confounders (covariates) of the selected subject.
- Collect, analyse, and preprocess suitable data.
- Select suitable models and estimate **treatment effect**.
- Validate results and interpret and communicate findings.

#### Contents:
The main project file is available in the Jupyter notebook 'caus_inf_spec.ipynb'. The final presentation is available in the 'Causal Inference.pptx' PowerPoint file. Downloading the file may be necessary for viewing.

All of the core project details can be found in the Jupyter notebook, while a comprehensive overview is available in the PowerPoint. Any feedback or suggestions would be greatly appreciated.
